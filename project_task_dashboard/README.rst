Project Task Dashboard
======================

This module adds a dashboard to the Project app in Odoo 16, showing the total number of tasks with quick filters for:

- This week
- This month
- Previous week
- Previous month

Features:
---------
- Simple dashboard card for total tasks
- Filter buttons for common time periods
- Uses Odoo's default project module

How to use:
-----------
- Go to Project > Task Dashboard
- Use the filter buttons to see the total number of tasks for each period
